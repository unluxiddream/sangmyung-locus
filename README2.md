# 에디터's Pick 작성 가이드

에디터's Pick은 각자 다녀온(또는 추천하는) 여행을 **블로그 글처럼** 소개하는 코너예요.
말투, 이야기 구성, 사진 고르는 방식은 **자유**예요. 대신 **파일 형식만** 아래 규칙대로 맞춰 주세요.
형식이 같아야 사이트가 모든 글을 같은 디자인으로 보여줄 수 있어요.

---

## 1. 파일 만들기

- **위치**: `content/ko/<지역>/editor-pick/` 폴더 (예: `content/ko/jeolla/editor-pick/`)
  - 지역 폴더 이름: `kangwon` 강원 / `gyeongsang` 경상 / `jeolla` 전라 / `chungcheong` 충청
  - `editor-pick` 폴더가 없으면 새로 만들면 돼요.
- **파일 이름**: `글 제목.md` (예: `남해 2박3일.md`)
  - 파일 이름 앞뒤에 띄어쓰기를 넣지 마세요.

---

## 2. 맨 위 정보 칸 (YAML) 채우기

**처음에 준 여행지 템플릿을 그대로** 맨 위에 붙여 넣어요. 에디터's Pick 글에서는 아래처럼 채우면 돼요.

```yaml
---
aliases:
cover: https://대표-사진-주소.jpg
info: 글을 한 줄로 소개하는 문장
주소:
문의:
휴일:
입장료:
주차:
대중교통:
홈페이지:
영업시간:
대지역:
  - 경상남도
메인 테마:
서브 테마:
코스:
  - I
---
```

| 항목 | 쓰는 법 |
|---|---|
| `cover` | 글의 **대표 사진 1장** 주소. 목록 카드에 표지로 나와요. |
| `info` | 카드에 보이는 **한 줄 소개** (예: `물때가 정한 하루, 남해에서 보낸 2박 3일`) |
| `대지역` | 여행한 지역의 도 이름. `강원도`, `충청북도`, `충청남도`, `전라북도`, `전라남도`, `경상북도`, `경상남도` 중에서 골라요. |
| `코스` | **자신의 이니셜** (`J` 강원도 / `H` 경상도 / `I` 전라도 / `A` 충청도). 이 값으로 글이 어느 에디터 페이지(예: I의 전라도)에 실릴지 정해져요. |
| 나머지 (`주소`, `문의`, `영업시간` 등) | **비워 두세요.** 장소 정보는 3번의 방문 정보 링크로 자동으로 붙어요. |

---

## 3. 본문 쓰기: Markdown 문법만 사용

본문은 **Markdown 문법으로만** 써 주세요.

**HTML 태그(`<div>`, `<p>`, `<img>`, `<table>`, `style="..."` 등)는 쓰지 마세요.**
VS Code나 Obsidian 미리보기에서는 HTML이 예쁘게 보이지만, 사이트에서는 그대로 보이지 않아요. 글꼴, 정렬, 크기, 사진 모서리 같은 디자인은 사이트가 한꺼번에 입혀요.

### 자주 쓰는 문법

| 하고 싶은 것 | 이렇게 쓰기 |
|---|---|
| 글 제목 (맨 처음 한 번) | `# 물때가 정한 하루, 남해에서 보낸 2박 3일` |
| 큰 소제목 (일차 등) | `## [DAY 1] 물을 막지 않고, 흐르는 방향을 읽는 사람들` |
| 작은 소제목 (장소별) | `### 해천멸치쌈밥 \| 바다에 도착하자마자 밥부터` |
| 문단 나누기 | 문단 사이에 **빈 줄 한 줄** |
| 문단 안에서 줄바꿈 | 줄 끝에 **띄어쓰기 두 칸** |
| 굵게 | `**굵게 쓸 말**` |
| 목록 | 줄 앞에 `- ` |
| 외부 링크 | `[보여줄 글자](https://주소)` |

```markdown
# 물때가 정한 하루, 남해에서 보낸 2박 3일

여러분 안녕하세요~! 오랜만이에요  
이번 포스팅은 남해 여행 이야기로 채우려고 해요!

## [DAY 1] 물을 막지 않고, 흐르는 방향을 읽는 사람들

해천멸치쌈밥 → 죽방렴 홍보관 → 죽방렴 관람대 → 지족반점 → 고요별서

### 해천멸치쌈밥 | 바다에 도착하자마자 밥부터

든든하게 먹고 돌아다니고 싶어 해천멸치쌈밥에 먼저 들렀습니다!
```

## 4. 이미지 넣기

### 쓰는 법

이미지는 **한 줄에 하나씩**, 위아래로 빈 줄을 두고 넣어요.

```markdown
![멸치쌈밥 한 상](https://mblogthumb-phinf.pstatic.net/....jpg?type=w800)
```

- `[ ]` 안에는 **사진 설명**을 써요 (예: `멸치쌈밥 한 상`). 사진이 안 뜰 때 대신 보이고, 화면 낭독기도 이 글을 읽어요.
- `( )` 안에는 **이미지 주소**를 넣어요.

### 이미지 주소 가져오기

1. 웹에서 사진에 **마우스 오른쪽 클릭 → "이미지 주소 복사"**를 눌러요. ("링크 주소 복사"가 아니에요.)
2. 복사한 주소를 **새 탭 주소창에 붙여 넣어서 사진만 크게 뜨는지** 확인해요.
3. 사진만 뜨면 `( )` 안에 붙여 넣어요.

### 이미지 출처 주의

| 써도 되는 곳 | 피해 주세요 |
|---|---|
| 네이버 블로그 (`pstatic.net`) | 카카오·티스토리·브런치 블로그 (`kakaocdn.net`): 시간이 지나면 주소가 만료돼요 |
| 지자체·관광공사 공식 사이트 | 인스타그램 (`cdninstagram.com`): 주소가 금방 만료돼요 |
| 위키미디어 공용 (`wikimedia.org`) | 구글 이미지 검색 결과의 작은 미리보기 (`gstatic.com`, `encrypted-tbn`) |

- 내 컴퓨터에 있는 사진 파일은 지금은 넣을 수 없어요. 인터넷 주소가 있는 사진만 써 주세요.
- `cover`에 넣은 대표 사진도 같은 규칙을 지켜 주세요.

## 5. 방문 정보 넣기: 장소 링크

방문 정보 표(주소, 운영시간 등)는 **직접 쓰지 마세요.**
대신 장소 이름을 아래처럼 쓰면, 사이트가 **우리 자료(장소 md)에 있는 정보로 방문 정보 박스를 자동으로** 만들어요.
장소 정보가 바뀌어도 장소 md 하나만 고치면 모든 글에 반영되고, 영어·일본어 화면에서도 자동으로 번역돼요.

### 방문 정보 박스: `![[장소명]]`

그 장소 이야기가 끝나는 곳에 한 줄로 넣어요.

```markdown
### 죽방렴 홍보관 | 전통 어업에 대해 알아보는 시간

전통 어업 방식에 대해 배울 수 있는 공간이에요~

![[죽방렴 홍보관]]
```

→ 그 자리에 **📍 죽방렴 홍보관 방문 정보 박스**가 나오고, 누르면 해당 장소 상세 페이지로 이동해요.

### 글 속 링크만: `[[장소명]]`

박스 없이 문장 안에서 장소 이름만 링크로 걸고 싶을 때 써요.

```markdown
점심 겸 저녁을 [[지족반점]]에서 먹었어요.
```

### 장소명 쓰는 규칙

- `[[ ]]` 안의 이름은 **`content/ko` 안에 있는 장소 파일 이름과 글자 하나까지 똑같아야** 해요. 띄어쓰기도 같아야 해요. (`.md`는 빼고)
  - 예: 파일이 `죽방렴 홍보관.md`이면 `![[죽방렴 홍보관]]`
- **Obsidian을 쓰면** `[[`까지 입력했을 때 장소 이름이 자동완성으로 떠요. 오타를 막는 가장 쉬운 방법이에요.
- 이름이 맞지 않는 장소는 빌드할 때 "확인이 필요한 항목"으로 알려줘요. 사이트에는 박스 없이 장소 이름만 보여요.

### 우리 자료에 없는 장소라면

식당·카페처럼 아직 장소 md가 없는 곳은 둘 중 하나로 해 주세요.

1. **장소 md를 먼저 만들기**: 여행지 템플릿으로 해당 지역의 `local-spot` 폴더에 장소 파일을 만들고, 글에서는 `![[장소명]]`으로 연결해요. (추천)
2. **간단히 직접 쓰기**: 장소 md를 만들기 어렵다면, 아래처럼 목록으로만 적어요. 표나 HTML은 쓰지 마세요.

```markdown
**📍 해천멸치쌈밥 | 방문 정보**

- **주소:** 경남 남해군 창선면 지족리 297
- **문의:** 055-867-1711
- **운영시간:** 09:00~20:00
```

## 6. 제출 전 체크리스트

- [ ] 파일 위치: `content/ko/<지역>/editor-pick/글 제목.md`
- [ ] 맨 위 템플릿이 있고, `cover`, `info`, `대지역`, `코스`(내 이니셜)를 채웠다
- [ ] 본문에 HTML 태그(`<div>`, `<img>`, `<table>`, `style=` 등)가 없다
- [ ] 이미지는 `![설명](주소)` 형식이고, 주소를 새 탭에서 열면 사진이 뜬다
- [ ] 카카오·인스타그램·구글 미리보기 이미지를 쓰지 않았다
- [ ] 방문 정보는 `![[장소명]]`으로 넣었고, 장소명이 파일 이름과 똑같다
- [ ] 우리 자료에 없는 장소는 장소 md를 만들었거나, 목록으로 간단히 적었다
